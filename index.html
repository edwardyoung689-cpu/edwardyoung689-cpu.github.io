Trading Mail Chart Import (Personal)

This personal application helps its owner receive alerts and organize trading-related source material. It is operated for personal use.

What the application does

  • Monitors configured trading execution data and selected Telegram channel updates, then emails alerts to the account owner.
  • Uses Gmail to send alerts and checks message metadata to reconcile delivery, reduce duplicates, and group related alerts into conversations.
  • In separately configured workflows, reads selected incoming mail and associated images to prepare local reference charts; Google Cloud Pub/Sub can provide notification of new mail.

Trading data is used for monitoring and reference. These alert workflows do not place or change trades.

How Google data is used

The application requests the Google permissions needed for the functions the owner enables. The separate alert sender uses Gmail send and metadata permissions. Configured incoming-mail workflows may request Gmail read-only and Pub/Sub permissions. See the Privacy Policy for details.
